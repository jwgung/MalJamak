소리·화면 설정

조각은 문장 끝 → 말 멈춤 → "~다, ~요, ~고, ~는데" 같은 어미 순으로 자연스러운 곳에서 자릅니다. 소리 입력·언어·인식 방식·조각 설정은 자막을 다시 시작해야 적용됩니다.

Enter 내보내기(고친 내용 포함) · Shift+Enter 내보내고 줄바꿈(나간 조각은 줄바꿈 켜기/끄기) · Esc 버리기 · ↑↓ 이동 · Ctrl+Enter 대기 중 모두 내보내기 · Insert 이 조각 뒤에 직접 입력 · 보라색은 강사 원어의 기계 번역 제안(확인해야 나감) · 고치기 시작하면 카운트다운이 멈춥니다 ·
